# Large Protein Complex Analysis
This project is being done within the [Brown Lab](https://brown.hms.harvard.edu/) at Harvard Medical School during the summer of 2022 by Nicholas Shaw.
## What does this do?
The goal of this project is to develop a method to generate models of large protein complexes using 
[AlphaFold Multimer](https://github.com/deepmind/alphafold). Running many large proteins in a single AlphaFold Multimer 
run is currently not possible for most scientist. This project aims to fill in this gap by running many small 
iterations of AlphaFold and then analyzing the likelihood of these protein-protein interactions occuring in nature.

# Final Update
The final project was completed with much of the code not tracked on GitHub. I have included the final poster that was developed as a result of this work, and after reviewing the project in April 2026, there are so many issues that need to be fixed.
The work done here is no longer directly relevant due to the explosion of AI and bioinformatic techniques within the structural biology space, but the principles of this work could still apply.
For these reasons, I am not going to fix this repo and project due to the lack of relevance and massive amount of work required. I will leave this repo public as a record of the progress I have made over the past 4 years.
